# Changelog

All notable changes to Agent Memory Vault will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows semantic versioning where practical.

## [Unreleased]

## [0.2.0] - 2026-04-29

### Added

- Always-On Memory Gate documentation and installation snippets.
- Public decision records under `docs/decisions/`, starting with Always-On Memory Gate.
- skills.sh publishing guide and public install command documentation.
- Public decision record for skills.sh / `skills` CLI distribution.

### Changed

- Clarified that agents should run lightweight memory relevance and persistence checks for every interaction while staying quiet when no memory action is needed.
- Promoted skills.sh / the `skills` CLI as a public distribution channel.

## [0.1.0] - 2026-04-29

### Added

- Initial open-source release scaffold.
- Portable `agent-memory-vault` skill for AI coding agents.
- Memory Gate with retrieval and persistence rules.
- Structured Prompt Gate inspired by SPDD/REASONS-style workflows.
- Generic memory pack templates.
- Open-source project docs and governance files.
